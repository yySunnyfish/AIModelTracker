## 二、架构决策

### 2.1 数据访问方式：方案 C（推荐）

| 操作类型 | 实现方式 | 原因 |
|---------|---------|------|
| 读取数据 | Next.js 15 Server Components 直查 Supabase | 零 API 样板、SSR、不暴露 schema |
| 保存结果（计算器/选型器） | API Routes (`/api/tools/*`) | 后续加认证方便，统一写入入口 |
| 未来批注/管理写操作 | API Routes | 同上 |

### 2.2 认证策略

- **P0/P1/P2 阶段**：读取全部公开，无需登录
- **写操作**（计算结果保存）：使用 Supabase `anon` key，无 RLS 限制（P3 阶段再加）
- **认证系统**（登录页、角色守卫）延至 P3

### 2.3 `lib/supabase.ts` 拆分

```
lib/
  supabase/
    server.ts   ← createServerClient()，Server Components 专用
    client.ts   ← createBrowserClient()，'use client' 组件专用
  db/
    models.ts       ← 模型查询函数
    companies.ts    ← 公司查询函数
    benchmarks.ts   ← Benchmark 趋势查询函数
    tools.ts        ← 计算器/选型器结果 CRUD
```

### 3.2 新增迁移：工具结果表

文件：`database/migrations/002_tools_results.sql`

```sql
-- 价格计算器历史
CREATE TABLE IF NOT EXISTS price_calc_results (
  id          UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  session_id  TEXT NOT NULL,              -- 浏览器 localStorage key，标识一次会话
  input_tokens_m   NUMERIC NOT NULL,      -- 输入量（百万 token）
  output_tokens_m  NUMERIC NOT NULL,
  model_ids   UUID[] NOT NULL,            -- 选中的模型 ID 数组
  result_json JSONB NOT NULL,             -- 完整计算结果快照
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- 基座选型器历史
CREATE TABLE IF NOT EXISTS selector_results (
  id              UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  session_id      TEXT NOT NULL,
  task_type       TEXT NOT NULL,          -- code_generation | long_context | multimodal | agent
  deployment      TEXT NOT NULL,          -- api | local
  priorities_json JSONB NOT NULL,         -- 权重设置
  recommendations_json JSONB NOT NULL,    -- 推荐结果快照
  created_at      TIMESTAMPTZ DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_price_calc_session ON price_calc_results(session_id, created_at DESC);
CREATE INDEX idx_selector_session ON selector_results(session_id, created_at DESC);
```

## 五、P2 — 决策工具

### 5.1 价格计算器 `/tools/price-calculator`

**布局**：左配置面板（240px）/ 右结果面板（实时更新）

**左侧面板**：
- 输入量滑块（M tokens/月，范围 1–1000）
- 输出量滑块（M tokens/月，范围 1–500）
- 模型多选（Combobox，可搜索，上限 6 个）
- `[计算]` 按钮（实时触发，无需手动点）
- `[保存此次结果]` 按钮 → POST `/api/tools/price-calculator`

**右侧面板**：
- 横向条形图（Recharts BarChart），按月费排序
- 最佳值（最低费用）标注 ⭐
- 推荐文字："M2.7 每年节省 $X，SWE-bench 差距 Y pp"
- 历史记录折叠区（展示最近 5 次保存的计算，从 `price_calc_results` 查询）

**API Route** `POST /api/tools/price-calculator`：
```typescript
// 请求体
{ session_id, input_tokens_m, output_tokens_m, model_ids, result_json }
// 响应
{ id, created_at }
```

### 5.2 基座选型器 `/tools/selector`

**布局**：左配置面板（260px）/ 右推荐列表（实时重排）

**左侧面板**：
- 任务类型 Select（代码生成 / 长上下文 / Agent / 多模态）
- 部署方式 Select（API / 本地部署）
- 月预算输入（USD）
- 4 个权重滑块（性能 / 成本 / 合规 / 灵活性），实时归一化到 100%
- `[保存推荐结果]` 按钮 → POST `/api/tools/selector`

**右侧面板**：
- 推荐卡片列表（#1/#2/#3），含：
  - 综合得分（0–100）
  - 得分拆解进度条（性能 × 成本 × 合规 × 灵活性）
  - 推荐原因 tags（"SWE 82%" / "成本极低" / "API 即用"）
  - 警告 tags（"闭源" / "超预算"）
- 调整权重时，卡片顺序实时动画重排

**评分算法**（纯前端计算，不依赖 API）：
```
total_score = Σ (weight_i × normalize(metric_i))

性能得分 = weighted_avg(swe_bench, mmlu) / 100
成本得分 = 1 - (model_price / max_price_in_set)
合规得分 = license === 'open' ? 1.0 : 0.5
灵活性得分 = deployment === 'api' ? 0.8 : (license === 'open' ? 1.0 : 0.2)
```

**API Route** `POST /api/tools/selector`：
```typescript
{ session_id, task_type, deployment, priorities_json, recommendations_json }
```
